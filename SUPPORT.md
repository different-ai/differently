# Getting help

- **Documentation:** <https://different-ai.github.io/differently/docs/>.
  Start with the [quickstart](docs/guides/quickstart.md) and
  [deployment overview](docs/deploy/README.md).
- **Questions and ideas:** open a
  [GitHub issue](https://github.com/different-ai/differently/issues/new/choose).
  Choose the feature request form for ideas, or the bug report form for
  something broken.
- **Bugs:** use the bug report form. Include the version
  (`differently-server version`), how you deployed it, the backend (OpenSandbox
  runtime, the provider's adapter kind, or a plugin), and `differently doctor` output.
- **Security issues:** never in a public issue; follow [SECURITY.md](SECURITY.md).

Differently is pre-release and maintained by the OpenWork team on a
best-effort basis. There is no paid support yet.
