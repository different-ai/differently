1. Read the bootstrap operator token (admin scope; store it in a vault):

     export DIFFERENTLY_API_KEY=$(kubectl get secret -n {{ $ns }} {{ $tokens }} \
       -o jsonpath='{.data.{{ .Values.auth.bootstrapTokenKey | replace "." "\\." }}}' | base64 -d)
{{- if not .Values.auth.existingSecret }}

   The token was generated once and is kept across upgrades. Tools that
   render with `helm template` (Argo CD, Flux post-renderers) cannot keep it:
   use auth.existingSecret there.
{{- end }}

2. Open the API and dashboard:
{{- if and .Values.ingress.enabled $public }}

     export DIFFERENTLY_URL={{ $public }}
     open "$DIFFERENTLY_URL/dashboard/"
{{- else }}

     kubectl port-forward -n {{ $ns }} svc/{{ $server }} 8080:{{ .Values.server.service.port }}
     export DIFFERENTLY_URL=http://127.0.0.1:8080
     open "$DIFFERENTLY_URL/dashboard/"     # paste the token when asked
{{- end }}

     curl -fsS "$DIFFERENTLY_URL/readyz"
     curl -fsS -H "Authorization: Bearer $DIFFERENTLY_API_KEY" "$DIFFERENTLY_URL/v1/admin/trust-report"
{{- if .Values.agent.enabled }}

3. Node agents run only on nodes labelled differently.dev/kvm=true:

     kubectl get nodes -l differently.dev/kvm=true
     kubectl get pods -n {{ $ns }} -l app.kubernetes.io/component=agent -o wide
     kubectl logs -n {{ $ns }} <agent-pod> -c doctor     # KVM/tun/kernel/image checks
     curl -fsS -H "Authorization: Bearer $DIFFERENTLY_API_KEY" "$DIFFERENTLY_URL/v1/admin/agents"
{{- if eq (.Values.agent.updateStrategy.type | default "") "OnDelete" }}

   Agents use updateStrategy OnDelete: `helm upgrade` does not restart them,
   because a restart stops that node's microVMs. Roll them node by node
   (docs/deploy/day-2.md).
{{- end }}
{{- end }}

{{- if and (not .Values.test.existingSecret) (not .Values.test.projectId) }}

   The bootstrap key is an operator key and must name a project. Create an
   organization and project first (docs/deploy/kubernetes.md), then:

     helm upgrade {{ .Release.Name }} <chart> -n {{ $ns }} --reuse-values --set test.projectId=prj_...

     helm test {{ .Release.Name }} -n {{ $ns }} --logs
