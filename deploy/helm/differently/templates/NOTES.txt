The server reads the OpenSandbox server's API key from key {{ $key }} of
Secret {{ $secret }}. Server pods wait until it exists; create it with:

     kubectl create secret generic {{ $secret }} -n {{ $ns }} \
       --from-literal={{ $key }}='<the OpenSandbox server api_key>'

Pool "{{ $o.pool.name }}" is declared trust={{ $o.trust }} and isolation={{ $o.isolation }}.
{{- if eq $o.trust "private" }}

runtime; set opensandbox.trust=external otherwise.
{{- else }}
As an external pool it receives work only when config.policy.external allows
it and config.policy.externalPools lists "{{ $o.pool.name }}".
{{- end }}
{{- if eq $o.isolation "container" }}
Containers share the host kernel. Set opensandbox.isolation=microvm only for

{{- else }}
Fast Sandbox has not been verified with Differently yet, so treat microVM
isolation as declared, not proven.
{{- end }}
Differently reports the declared isolation; it does not enforce isolation or
sandbox egress itself.

1. Read the bootstrap operator token (admin scope; store it in a vault):

     export DIFFERENTLY_API_KEY=$(kubectl get secret -n {{ $ns }} {{ $tokens }} \
       -o jsonpath='{.data.{{ .Values.auth.bootstrapTokenKey | replace "." "\\." }}}' | base64 -d)
{{- if not .Values.auth.existingSecret }}

   The token was generated once and is kept across upgrades. Tools that
   render with `helm template` (Argo CD, Flux post-renderers) cannot keep it:
   use auth.existingSecret there.
{{- end }}

2. Open the API and dashboard:
{{- if and .Values.ingress.enabled $public }}

     export DIFFERENTLY_URL={{ $public }}
     open "$DIFFERENTLY_URL/dashboard/"
{{- else }}

     kubectl port-forward -n {{ $ns }} svc/{{ $server }} 8080:{{ .Values.server.service.port }}
     export DIFFERENTLY_URL=http://127.0.0.1:8080
     open "$DIFFERENTLY_URL/dashboard/"     # paste the token when asked
{{- end }}

     curl -fsS "$DIFFERENTLY_URL/readyz"
     curl -fsS -H "Authorization: Bearer $DIFFERENTLY_API_KEY" "$DIFFERENTLY_URL/v1/admin/trust-report"
