# Differently

**Run VMs differently: own them.** Your infrastructure. Your rules. One API.

Differently is an open-source (Apache-2.0), fully self-hosted control plane for
sandboxes and Firecracker microVMs, with optional policy-gated placement on
external providers. Built by the OpenWork team.

**There is no release yet.** All development happens on the
[`pre-release`](https://github.com/different-ai/differently/tree/pre-release)
branch, which is the repository's default branch. `main` receives code only
when a release is cut from `pre-release`; see
[CONTRIBUTING.md](CONTRIBUTING.md) for the branch model.
